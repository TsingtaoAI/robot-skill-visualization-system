# Go2 Robot Skill Visualization System

基于 Genesis、PyTorch 和 Viser 构建的 Unitree Go2 机器人技能可视化与交互演示系统。

系统加载预训练强化学习策略，在物理仿真环境中实现 Go2 的基础行走、高动态技能、自主导航和浏览器实时遥控。

## 功能特性

### 高动态技能演示

系统内置多个预训练技能策略：

- 前脚倒立
- 后腿站立循环
- 单次后空翻
- 向前弹跳
- 连续后空翻

支持技能触发、急停、复位、重放、执行状态显示和场景截图。

### 自主导航

导航模块实现：

- 360° LiDAR 扫描
- 占据栅格地图
- 障碍物膨胀
- A* 路径规划
- 动态重新规划
- 近距离障碍排斥
- 路径、点云和占据地图可视化
- 点击三维场景或输入坐标设置终点

A* 负责生成导航路线，预训练强化学习策略负责控制机器人按照速度指令行走。

### 运动遥控

支持通过浏览器控制 Go2：

- `W/S`：前进、后退
- `A/D`：左右横移
- `Q/E`：左右转向
- 一键停止和复位
- 速度幅度调节
- 步态周期调节
- 机身高度调节
- 相机跟随和自由视角

支持以下步态：

- Trot：对角小跑
- Bound：前后跳跃
- Pace：对侧跑步
- Pronk：四足齐跳

### Web 门户

统一门户提供：

- 模块状态检测
- 一键启动和停止
- 运行日志查看
- 技能、导航和遥控页面入口
- GPU 与 CPU 两种运行方式
