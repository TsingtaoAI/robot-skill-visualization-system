# 机器人技能可视化演示交互系统

基于 **Genesis、PyTorch 和强化学习**构建的 Unitree Go2 机器人仿真演示系统。

项目通过加载预训练策略，实现 Go2 的高动态技能、自主导航和运动控制，并使用 Viser 对机器人状态、运动过程和规划结果进行三维可视化。

## 🤖 主要功能

### 高动态技能

项目内置多个训练完成的技能策略：

- 前脚倒立
- 后腿站立循环
- 单次后空翻
- 连续后空翻
- 向前弹跳

系统能够根据机器人当前姿态实时计算关节动作，并完成动作交接、落地检测和站稳恢复。

### 自主导航

导航模块实现了：

- 360° LiDAR 扫描
- 占据栅格建图
- 障碍物膨胀
- A* 路径规划
- 动态重新规划
- 近距离避障
- 路径和点云可视化

A* 负责规划移动路线，强化学习行走策略负责控制机器人沿规划方向运动。

### 运动控制

项目包含训练完成的 Go2 行走智能体，可以接收高层速度指令，实现：

- 前进和后退
- 左右横移
- 左右转向
- 停止和复位
- 步态切换
- 步态周期和机身高度调节

支持对角小跑、前后跳跃、对侧跑步和四足齐跳等步态。

## 🧠 强化学习的作用

强化学习策略负责把速度或技能指令转换成 Go2 的 12 个关节动作：

```text
速度指令 / 技能指令
          ↓
   预训练强化学习策略
          ↓
  12 个关节控制指令
          ↓
   Genesis 物理仿真
```

项目正常运行时直接加载已有模型进行推理，不会重新训练智能体。

## 📁 核心目录

```text
rsvs/
├── skills/        # 高动态技能
├── nav/           # LiDAR 与自主导航
├── play/          # 行走策略和运动控制
├── common/        # 三维显示与公共组件
├── weights/       # 预训练策略权重
├── assets/        # Go2 和场景模型
├── legged_gym/    # 机器人仿真环境
└── rsl_rl/        # 强化学习算法框架
```

## ⚠️ 项目说明

当前项目主要用于 Genesis 仿真研究和机器人技能演示，尚未直接连接 Unitree 实机 SDK、ROS 或真实电机控制接口。

如需部署到实体机器人，还需要完成通信接口、安全保护和 Sim-to-Real 适配。
