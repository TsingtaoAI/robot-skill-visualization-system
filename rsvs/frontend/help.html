软件信息

软件全称：机器人技能可视化演示交互系统 · 版本 V1.0。本系统提供统一 Web 门户与三维可视化交互控制，调用仿真与策略模块完成技能/导航/遥控演示。

运行环境

  • 操作系统：Linux（推荐 Ubuntu）；浏览器 Chrome / Edge / Firefox
  • Python：conda 环境 lr_gen（Python 3.10）；依赖与 LeggedGym-Ex · Genesis 一致
  • 硬件：建议 NVIDIA GPU；无 GPU 时启动命令追加 --cpu
conda create -n lr_gen python=3.10 -y
conda activate lr_gen
pip install torch==2.8.0 torchvision==0.23.0 --index-url https://download.pytorch.org/whl/cu126
cd newtest
pip install -e ".[genesis]"

说明：勿再单独 pip 安装零散的 genesis-world / rsl-rl 清单；由上述 editable 安装拉取正确版本。SIMULATOR=genesis 已由 run.sh 默认设置。

启动命令

conda activate lr_gen
./newtest/run.sh hub --port 8090
./newtest/run.sh skills --port 8081
./newtest/run.sh nav --port 8082
./newtest/run.sh play --port 8083

常见问题

  • 门户显示「未启动」：先启动对应 run.sh，或点「启动并打开」等待就绪。
  • 三维页无法连接：检查端口占用与防火墙；远程访问时门户会用当前主机名打开演示。
  • 技能按钮无响应：等待当前技能完成，或按 Esc / 点复位。
  • 结束演示：关闭三维网页，或点门户「停止演示」；门户终端 Ctrl+C 结束门户。
