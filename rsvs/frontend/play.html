运动遥控演示

本页用 WASD 遥控机器狗；相机改到 IJKL。底坞可切换步态、幅度、周期与高度档位。

检测中
移动

W A S D

按住给出固定前后/侧向速度，松手停止；幅度档可整体缩放。

转向

Q / E

按住给出固定偏航角速度，松手停止。

步态 / 档位

1–4 · 5–7 · ZXC · VNM

步态、幅度上限、周期与机身高度档位快捷切换。

相机

I J K L

本页相机平移改到 IJKL；U/O 升降；方向键旋转。仅本页有效。

快捷键功能
W / S纵向速度 ±（机器狗）
A / D侧向速度 ±（机器狗）
Q / E偏航角速度 ±
B / Space速度归零急停
1–4切换步态类型（单选高亮）
5 / 6 / 7指令幅度 ×0.3 / ×0.7 / ×1.0
Z / X / C步态周期 慢 / 中 / 快
V / N / M机身高度 低 / 中 / 高
R / F复位站立 / 前进反向
底坞「自由相机」解锁后 IJKL/UO/方向键控制视角
底坞「锁定相机」跟随机器人
